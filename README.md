## User Stories

### Home Page

- As a visitor, I want to access designs and companies from the home page so that I can start exploring easily. (Home Navigation)
- As a visitor, I want to see project preparation tips so that I know what to discuss with a designer. (Project Preparation Tips)
- As a visitor, I want to watch short interior design videos so that I can discover ideas for my home. (Interior Design Videos)

### Authentication and Profile Management

- As a customer, I want to register an account so that I can contact designers about their designs. (Customer Registration)
- As a company, I want to register an account so that I can join the platform. (Company Registration)
- As a registered user, I want to log in and log out so that I can access my account. (Login and Logout)
- As a registered user, I want to view and update my profile and change my password so that I can maintain my account information. (Profile Management)

### Design Discovery

- As a visitor or customer, I want to browse designs so that I can find inspiration for my home. (Design Browsing)
- As a visitor or customer, I want to search, filter, and sort designs so that I can find designs matching my preferences and budget. (Design Search and Filters)
- As a visitor or customer, I want to view a design's details and photos so that I can understand the project before making an enquiry. (Design Details)
- As a visitor or customer, I want to see related designs in the same category so that I can explore similar ideas. (Related Designs)

- As a designer, I want views to be recorded when guests or logged-in customers open my design details so that interest in my work can be tracked. (Design View Tracking)

### Design Statistics

- As Platform Management, I want to see view totals, daily trends, and the top five designs so that I can understand activity across the platform. (Platform Design Statistics)
- As a company, I want to see view statistics for my company's designs so that I can identify popular work. (Company Design Statistics)
- As a designer, I want to see view statistics for my own designs so that I can track interest in my portfolio. (Designer Design Statistics)
- As a dashboard user, I want to choose a reporting period so that I can compare recent and all-time design popularity. (Statistics Period Selection)

### Favourite Designs

- As a logged-in customer, I want to view my saved designs in the dashboard so that I can revisit their details. (Favourite Design Listing)

- As a logged-in customer, I want to add a design to my favourites from its card so that I can save ideas I like. (Add Favourite Design)
- As a logged-in customer, I want to remove a saved design from my favourites so that I can keep my list relevant. (Remove Favourite Design)

### Company Directory

- As a visitor or customer, I want to browse approved companies with images and contact details so that I can find professionals for my project. (Company Browsing)
- As a visitor or customer, I want to search companies by name or email so that I can find a specific company. (Company Search)
- As a visitor or customer, I want to browse companies across pages so that I can explore the directory at my own pace. (Company Pagination)
- As a visitor or customer, I want to visit a company's website or contact it by email or phone so that I can learn more about its services. (Company Contact Details)

### Company Designer Management

- As a company, I want to view my designers' names and emails so that I can identify who belongs to my company. (Company Designer Listing)

- As a company, I want to register a designer using their email, first name, and last name so that they can join my company. (Designer Registration)
- As a company, I want to see the server's registration confirmation or error message so that I know whether the designer account was created successfully. (Registration Feedback)

### Designer Profile

- As a designer, I want to update my years of experience and biography so that customers can learn about my background and design approach. (Designer Profile Update)

### Designer Portfolio Management

- As a designer, I want to view and search my designs so that I can manage my portfolio. (Portfolio Search)
- As a designer, I want to create designs and upload photos so that customers can discover my work. (Design Creation)
- As a designer, I want to update or delete my designs so that my portfolio stays current. (Design Editing and Deletion)

### Company Design Management

- As a company, I want to create a design for a designer so that I can add work to their portfolio. (Company Design Creation)
- As a company, I want to choose a designer by email when creating a design so that the work is assigned to the correct designer. (Designer Selection)
- As a company, I want to search, edit, and delete designs so that I can keep the portfolio current. (Company Design Management)
- As a company, I want to mark designs as Reviewing or Approved so that I can manage their review status. (Design Approval)
- As a designer, I want to see my designs' review statuses so that I can track company approval. (Design Review Status)
- As a company, I want separate areas for designs and designers so that I can find the management tools I need. (Company Dashboard Tabs)

### Design Enquiry Management

- As a customer, I want to send an enquiry about a design so that I can discuss my project with the designer. (Design Enquiry)
- As a customer or designer, I want to view my enquiries and their statuses so that I can track ongoing conversations. (Enquiry Tracking)
- As a customer or designer, I want to exchange messages and see conversation updates so that we can discuss project requirements. (Enquiry Messaging)
- As a designer, I want to mark an enquiry as completed so that finished conversations can be closed. (Enquiry Completion)
- As a customer or designer, I want to view completed conversations so that I can refer to previous discussions. (Enquiry History)

### Platform Account Management

- As Platform Management, I want to view and search customer and company accounts so that I can review registered accounts. (Account Search)
- As Platform Management, I want to approve, reject, or set company accounts to pending so that I can manage their account status. (Company Account Approval)

### Category Management

- As Platform Management, I want to view, create, update, and delete design categories so that designs can be organised consistently. (Category Management)

### General Enquiries

- As a visitor or registered user, I want to submit a general enquiry through Contact Us so that I can get in touch with the company. (General Enquiry)
- As a visitor or registered user, I want to see a submission confirmation so that I know my enquiry was sent successfully. (Enquiry Confirmation)

### Website Policies

- As a visitor or registered user, I want to read the website's policies so that I understand the guidelines for accounts, shared content, and communication. (Website Policies)
