## User Stories

### Home Page

1. As a visitor, I want to access designs and companies from the home page so that I can start exploring easily. (Home Navigation)
2. As a visitor, I want to see project preparation tips so that I know what to discuss with a designer. (Project Preparation Tips)
3. As a visitor, I want to watch short interior design videos so that I can discover ideas for my home. (Interior Design Videos)

### Authentication and Profile Management

4. As a customer, I want to register an account so that I can contact designers about their designs. (Customer Registration)
5. As a company, I want to register an account so that I can join the platform. (Company Registration)
6. As a registered user, I want to log in and log out so that I can access my account. (Login and Logout)
7. As a registered user, I want to manage my profile and password, including the personal information, company details, or designer biography and years of experience relevant to my account, so that my information remains accurate and up to date. (Profile Management)

### Design Discovery

8. As a visitor or customer, I want to browse designs so that I can find inspiration for my home. (Design Browsing)
9. As a visitor or customer, I want to search, filter, and sort designs so that I can find designs matching my preferences and budget. (Design Search and Filters)
10. As a visitor or customer, I want to view a design's details and photos so that I can understand the project before making an enquiry. (Design Details)
11. As a visitor or customer, I want to see the company details and contact information on a design's page so that I can learn about the team behind the project. (Design Company Details)
12. As a visitor or customer, I want to see related designs in the same category so that I can explore similar ideas. (Related Designs)
13. As a designer, I want views to be recorded when guests or logged-in customers open my design details so that interest in my work can be tracked. (Design View Tracking)

### Design Statistics

14. As Platform Management, I want to see view totals, daily trends, and the top five designs so that I can understand activity across the platform. (Platform Design Statistics)
15. As a company, I want to see view statistics for my company's designs so that I can identify popular work. (Company Design Statistics)
16. As a designer, I want to see view statistics for my own designs so that I can track interest in my portfolio. (Designer Design Statistics)
17. As a dashboard user, I want to choose a reporting period so that I can compare recent and all-time design popularity. (Statistics Period Selection)
18. As Platform Management, a company, or a designer, I want to see favourite totals, unique customers, and my top five most-favourited designs within my dashboard scope so that I can understand customer interest. (Favourite Statistics)
19. As a company, I want to see how many of my designers have designs saved by customers so that I can track interest across my team. (Designer Favourite Summary)

### Favourite Designs

20. As a logged-in customer, I want to view my saved designs in the dashboard so that I can revisit their details. (Favourite Design Listing)
21. As a logged-in customer, I want to manage my favourite designs so that I can keep a relevant collection of renovation ideas. (Favourite Design Management)

### Company Directory

22. As a visitor or customer, I want to browse approved companies across pages and access their websites, email addresses, and phone numbers so that I can find and contact professionals for my project. (Company Browsing and Contact)
23. As a visitor or customer, I want to search companies by name or email so that I can find a specific company. (Company Search)

### Company Designer Management

24. As a company, I want to view my designers' names and emails so that I can identify who belongs to my company. (Company Designer Listing)
25. As a company, I want to register a designer using their email and name and receive confirmation of the outcome so that I know whether they have joined my company successfully. (Designer Registration)

### Designer Portfolio Management

26. As a designer, I want to view and search my designs so that I can manage my portfolio. (Portfolio Search)
27. As a designer, I want to manage my design projects, photos, and project details so that my portfolio stays current and customers can discover my work. (Design Portfolio Management)

### Company Design Management

28. As a company, I want to create a design and assign one of my designers by email so that the work is added to the correct portfolio. (Company Design Creation and Assignment)
29. As a company, I want to manage company designs so that I can keep the portfolio current. (Company Design Management)
30. As a company, I want to mark designs as Reviewing or Approved so that I can manage their review status. (Design Approval)
31. As a designer, I want to see my designs' review statuses so that I can track company approval. (Design Review Status)
32. As a company, I want separate areas for designs and designers so that I can find the management tools I need. (Company Dashboard Tabs)

### Design Enquiry Management

33. As a customer, I want to send an enquiry about a design so that I can discuss my project with the designer. (Design Enquiry)
34. As a customer or designer, I want to view my ongoing and completed enquiries and their statuses so that I can track conversations and refer to previous discussions. (Enquiry Tracking and History)
35. As a customer or designer, I want to exchange messages and see conversation updates so that we can discuss project requirements. (Enquiry Messaging)
36. As a designer, I want to mark an enquiry as completed so that finished conversations can be closed. (Enquiry Completion)

### Platform Account Management

37. As Platform Management, I want to view and search customer and company accounts so that I can review registered accounts. (Account Search)
38. As Platform Management, I want to approve, reject, or set company accounts to pending so that I can manage their account status. (Company Account Approval)

### Category Management

39. As Platform Management, I want to manage design categories so that designs can be organised consistently. (Category Management)

### General Enquiries

40. As a visitor or registered user, I want to submit a general enquiry through Contact Us and receive a submission confirmation so that I know my message was sent successfully. (General Enquiry)

### Website Policies

41. As a visitor or registered user, I want to read the website's policies so that I understand the guidelines for accounts, shared content, and communication. (Website Policies)

## Additional Non-Implemented User Stories

### Platform Management

42. As a platform manager, I want to issue warnings with reasons to a company and see its warning history so that repeated breaches of platform rules can be identified. (Company Warning History)
43. As a platform manager, I want to investigate projects reported by users so that misleading content can be reviewed. (Reported Project Investigation)
44. As a platform manager, I want to merge overlapping categories and automatically reassign their projects so that customers receive consistent search results. (Category Merging)
45. As a platform manager, I want to set minimum project submission requirements so that incomplete projects are blocked before review. (Submission Requirements)
46. As a platform manager, I want to see customer search terms that returned no results so that I can identify missing categories or styles. (Unsuccessful Search Analysis)
47. As a platform manager, I want submissions that reuse another company's project photos to be flagged automatically so that I can investigate possible misattribution. (Duplicate Photo Detection)
48. As a platform manager, I want suspicious bursts of views or favourites to be flagged automatically so that I can investigate potentially inflated engagement figures. (Suspicious Engagement Detection)

### Company Features

49. As a company, I want to highlight featured projects on my company profile so that prospective customers can see our best work. (Featured Company Projects)
50. As a company, I want to publish time-limited promotions that expire automatically so that I can attract customers during campaigns. (Company Promotions)
51. As a company, I want to specify the regions we serve so that I receive enquiries from customers within our coverage area. (Company Service Regions)

### Designer Features

52. As a designer, I want to manage reusable enquiry reply templates so that I can respond to customers quickly and consistently. (Enquiry Reply Templates)
53. As a designer, I want to display paired before-and-after project photos using a comparison slider so that customers can see the transformation I delivered. (Before-and-After Comparison)
54. As a designer, I want to save a project as a draft and preview it before submission so that I can correct mistakes before requesting approval. (Project Drafts and Preview)
55. As a designer, I want to tag materials, paint colours, and furniture brands in a project so that customers can understand the components of the design. (Project Item Tags)
56. As a designer, I want uploaded project photos to be watermarked automatically with my company name so that my work is clearly attributed. (Automatic Photo Watermarks)

### Customer Features

57. As a customer, I want to view verified customer reviews and ratings on a company's profile so that I can assess its reliability before making contact. (Verified Company Reviews)
58. As a customer, I want to estimate renovation costs using my property type, size, and scope of work so that I can set a realistic budget before browsing. (Renovation Cost Estimate)
59. As a customer, I want to download a project's photos, specifications, budget, and company contact details as a PDF so that I can discuss the project offline. (Project PDF Download)
60. As a customer, I want to compare shortlisted projects side by side so that I can evaluate their costs, styles, and included work before contacting a designer. (Shortlisted Project Comparison)

## 12 Final User stories to be implement

### 6 Core User Stories

1. As a registered user, I want to manage my profile so that my information remains accurate and up to date. (Profile Management)
2. As a designer, I want to manage current and past design projects with photos and project details so that I can maintain my portfolio. (Design Portfolio Management)
3. As a customer, I want to search, filter, and sort designs so that I can find projects matching my preferences and budget. (Design Search and Filters)
4. As a designer, I want to see the number of views and favourites received by my designs so that I can understand customer interest in my work. (Design Interest Tracking)
5. As a platform manager, I want to manage design categories so that projects can be organised consistently. (Category Management)
6. As a platform manager, I want to view daily, weekly, and monthly engagement reports so that I can monitor platform usage. (Platform Engagement Reports)

### 6 Additional User Stories

7. As a customer, I want to exchange messages with a designer in a design enquiry so that I can discuss my renovation requirements. (Design Enquiry Messaging)
8. As a customer, I want to see related designs in the same category on a design's details page so that I can explore similar ideas without starting another search. (Related Design Recommendations)
9. As a company, I want to choose one of my designers by email when creating a design so that the project is assigned to the correct person in my team. (Company Designer Assignment)
10. As a company, I want to mark designs as Reviewing or Approved so that I can control which projects are ready for publication. (Company Design Approval)
11. As a customer, I want to view a design's details and photos so that I can assess whether the project matches my preferences. (Design Details)
12. As a customer, I want to manage my favourite designs so that I can save and revisit ideas when comparing renovation options. (Favourite Design Management)
